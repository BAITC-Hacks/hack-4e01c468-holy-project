## Frozen transport contract

All routes /api. Error payload `{"error":{"code":"safe_code","message":"safe user text"}}`; validation422, missing404, conflict409, unexpected500. Never raw exception repr.

```ts
type RunStatus = 'success' | 'degraded' | 'failed';
type RunView = {
  run_id: string; status: RunStatus; reused: boolean;
  manifest: Record<string, unknown>;
  metrics: Record<string, unknown>;
  events: Array<Record<string, unknown>>;
  report: string;
  forecast: Array<Record<string, string | number | null>>;
};
type JobView = {
  job_id: string;
  state: 'queued' | 'running' | 'completed' | 'failed';
  result: RunView | null;
  error: {code: string; message: string} | null;
};
```

GET /health -> `{status:'ok', mode:'demo'|'competition', offline:boolean}`.
GET /runs/latest -> `{run: RunView|null}`. GET /runs/{run_id} -> `{run:RunView}`.
POST /forecast-jobs JSON `{origin:string,horizon:24|48,refresh:boolean}` ->202 JobView.
GET /forecast-jobs/{job_id} -> JobView; completed includes even domain-failed RunView (transport success != forecast success).
GET /runs/{run_id}/forecast.csv -> text/csv attachment or404.
Forecast row fields remain existing artifact columns: inspect contracts/fixture CSV rather than rename backend columns.
